## Typography

Capture these from production:

- Font family.
- Base text size.
- Heading scale.
- Label scale.
- Tabular or monospace usage for addresses, hashes, slots, and amounts.
- Line-height strategy for dense tables.

## Spacing and Density

OrbMarkets should optimize for scan speed. Record exact spacing from production before finalizing:

- Page gutters.
- Header height.
- Table row height.
- Detail panel padding.
- Control height.
- Border radius.
- Breakpoints.

## Surfaces

Track how the product separates content:

- Full-page shell.
- Navigation surface.
- Table surface.
- Detail panels.
- Inline metadata groups.
- Modals, drawers, popovers, and menus.

## Icons

Document icon library or style when confirmed. For front-end consistency, each icon entry should define:

- Name or glyph.
- Size.
- Stroke weight.
- Color role.
- Hover and active behavior.
- Associated action or semantic meaning.
